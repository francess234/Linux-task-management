# Evidence folder

Keep your written command log in `command-log.md`. Add any additional non-sensitive evidence files here if needed.

Suggested evidence:
- User identity and home directory checks
- FHS navigation and directory inspection
- `ls`, `ls -l`, and `ls -a` outputs
- Workspace tree and file contents
- `find` and `grep` results
- Permission verification with `ls -l`

Never save passwords, private keys, access tokens, or other secrets.
